# Tushar Portfolio Workspace

This directory contains the workspace structure for the personal portfolio project:

- **`profile-source/`**: Clone of the existing GitHub profile repository containing source profile information, project references, and historical assets.
- **`portfolio-app/`**: Clone of the 3D Portfolio template repository ([Naresh-Khatri/3d-portfolio](https://github.com/Naresh-Khatri/3d-portfolio)) serving as the application foundation.
- **`context/`**: Contains structured markdown context files (`profile.md`, `projects.md`, `experience-and-achievements.md`, `links.md`) to guide portfolio content.
- **`reference/`**: Houses design notes and reference documentation (`design-notes.md`).
- **`public-assets/`**: Placeholder directory for approved media, screenshots, and downloadable assets.
