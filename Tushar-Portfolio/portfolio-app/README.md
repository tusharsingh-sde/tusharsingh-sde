## ✨ Features

- **Interactive 3D Keyboard** — Custom Three.js / Chibi3D interactive keyboard where each keycap represents an engineering skill, revealing titles and descriptions on hover, tap, or typing.
- **Project Showcase** — Interactive modal previews, responsive frames, and live demonstration links for AI/ML and backend systems.
- **Adaptive Performance** — Automatic device capability detection, dynamic DPR scaling, and battery-friendly frame rendering.
- **Live Multiplayer** — Realtime visitor presence, cursor sharing, and live communication.
- **Modern Animations** — Smooth scrolling with Lenis, Motion transitions, and responsive dialogs.
- **Theme Support** — Full dark/light mode toggle with view-transition animations.

## 🛠️ Tech Stack

| Layer | Technologies |
|---|---|
| **Framework** | Next.js 16 (App Router, Turbopack), React 19, TypeScript |

## 🚀 Getting Started

### Prerequisites

- Node.js 20.9+
- pnpm 11+

### Installation

1. **Clone the repository:**

    ```bash
    git clone https://github.com/tusharsingh-sde/tusharsingh-sde.git
    cd Tushar-Portfolio/portfolio-app
    ```

2. **Install dependencies:**

    ```bash
    pnpm install
    ```

3. **Run the development server:**

    ```bash
    pnpm dev
    ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build for Production

```bash
pnpm build
pnpm start
```
